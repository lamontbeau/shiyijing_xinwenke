# 西安陆港绿色效应测度项目 (2026年大学生新文科实践创新大赛·西安建筑科技大学管理学院)

## 项目简介

自动机器学习驱动西安陆港绿色效应测度与中欧班列联动路径探索

本项目运用随机森林、XGBoost等自动机器学习算法，融合卫星遥感、夜间灯光、货车GPS等多源大数据，评估西安国际陆港集结中心的环境、经济、社会三维效应，服务"一带一路"高质量发展。
